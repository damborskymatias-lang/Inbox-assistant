The `Sidebar` renders the navigation items registered by feature aspects, sorted by weight, each with an icon, label and an optional count badge. The item matching the current route is highlighted as active. On desktop it renders as a fixed column; below 1024px it slides in as an overlay drawer controlled by the `open` and `onClose` props.

## Basic usage

Render the sidebar with a list of navigation items. Wrap it with a router since it relies on the current route to highlight the active item.

```tsx
import { MemoryRouter } from 'react-router-dom';
import { Sidebar } from '@lov/inbox-platform.layout.sidebar';
import { DashboardIcon, HomeIcon } from '@lov/inbox-platform.icons.inbox-icons';

function BasicExample() {
  const navigationItems = [
    { label: `Dashboard`, href: `/dashboard`, icon: HomeIcon, weight: 0 },
    { label: `Inbox`, href: `/inbox`, icon: DashboardIcon, weight: 1, badge: () => 12 },
  ];

  return (
    <MemoryRouter initialEntries={['/dashboard']}>
      <div style={{ display: 'flex', height: '400px' }}>
        <Sidebar navigationItems={navigationItems} open />
      </div>
    </MemoryRouter>
  );
}
```

## Controlling the drawer

Below 1024px the sidebar behaves as an overlay drawer. Use the `open` and `onClose` props to control its visibility, typically from a hamburger button in the header.

```tsx
import { useState } from 'react';
import { MemoryRouter } from 'react-router-dom';
import { Sidebar } from '@lov/inbox-platform.layout.sidebar';
import { HomeIcon, SettingsIcon } from '@lov/inbox-platform.icons.inbox-icons';

function DrawerExample() {
  const [open, setOpen] = useState(false);
  const navigationItems = [
    { label: `Dashboard`, href: `/dashboard`, icon: HomeIcon, weight: 0 },
    { label: `Settings`, href: `/settings`, icon: SettingsIcon, weight: 1 },
  ];

  return (
    <MemoryRouter initialEntries={['/dashboard']}>
      <div style={{ position: 'relative', height: '400px' }}>
        <button onClick={() => setOpen(true)}>Open menu</button>
        <Sidebar navigationItems={navigationItems} open={open} onClose={() => setOpen(false)} />
      </div>
    </MemoryRouter>
  );
}
```

## Empty state

When no navigation items are registered yet, the sidebar shows a friendly empty message instead of an empty list.

```tsx
import { MemoryRouter } from 'react-router-dom';
import { Sidebar } from '@lov/inbox-platform.layout.sidebar';

function EmptyExample() {
  return (
    <MemoryRouter initialEntries={['/dashboard']}>
      <div style={{ display: 'flex', height: '200px' }}>
        <Sidebar navigationItems={[]} open />
      </div>
    </MemoryRouter>
  );
}
```
